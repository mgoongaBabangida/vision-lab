# Experiment notes

Store short, committed experiment descriptions here. Keep footage and generated
results in ignored `data/` and `runs/` folders.

For each experiment record:

- Question and expected behavior.
- Input identifier, dimensions, frame range, nominal FPS, and timestamp limitations.
- Commit, build preset, platform, OpenCV version, stage order, and parameter values.
- Command used, observations, timings, and a small representative result.
- What changed your understanding and what to try next.

Only add a reusable experiment executable or parameter file when it is needed.
